# Scanrail 0.1.3 릴리스 노트

릴리스 날짜: 2026-06-15

## 요약

Scanrail 0.1.3은 release readiness와 safety hardening을 위한 patch release입니다. scanner engine 범위를 넓히는 릴리스는 아닙니다. 기존 native headers scanner와 MCP MVP를 더 안전하게 검증하고, 감사 가능하게 만들며, OSS 배포 흐름을 더 명확히 합니다.

## 주요 변경

- MCP active-scan attempt가 로컬 audit evidence를 남깁니다.
- MCP Workbench 검증 경로를 문서화된 regression path에 포함합니다.
- report와 log에서 raw target 노출을 피하도록 scanner target redaction을 중앙화합니다.
- scanner capability metadata를 통해 safety enforcement gap을 암묵적으로 두지 않고 명시합니다.
- release risk register가 남은 risk를 release, MCP expansion, scanner adapter, roadmap gate로 매핑합니다.
- npm publish를 위한 release checklist와 risk treatment plan을 공개 문서에 추가합니다.

## 사용자 영향

기존 `scanrail doctor`, `scanrail init`, `scanrail setup`, `scanrail run --only headers`, `scanrail mcp serve` 흐름은 호환됩니다. npm으로 설치하는 사용자는 동일한 CLI surface를 사용하면서, audit와 safety 문서화가 강화된 버전을 받게 됩니다.

## 검증

게시 전에는 다음 gate를 통과해야 합니다.

```bash
npm run docs:check-links
npm test
make release-dry-run
npm run publish:dry-run
```

npm publish workflow는 GitHub Actions에서 아래 순서로 실행합니다.

```text
validate -> dry-run -> publish
```

## 비목표

이번 릴리스는 Docker 기반 Gitleaks, Trivy, Semgrep, OWASP ZAP adapter를 제공하지 않습니다. SARIF 출력도 stable report format으로 승격하지 않습니다. 해당 항목은 scanner adapter와 reporting expansion gate로 유지합니다.
