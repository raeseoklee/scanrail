# Scanrail 0.2.1 릴리스 노트

릴리스 일자: 2026-06-25

Scanrail 0.2.1은 v0.2 web/API 확장 트랙에서 conservative native OpenAPI baseline scanner를 추가합니다. local API contract를 읽고, remote spec fetch나 API endpoint 호출 없이 contract 수준의 보안 리뷰 신호를 리포트합니다.

## 변경 사항

- local OpenAPI baseline 점검용 `scanrail run --only openapi`를 추가했습니다.
- `scanrail init`과 `scanrail run`에 `--openapi <path>`를 추가했습니다.
- `scanrail.yaml`에서 `targets.api.openapi`를 parsing합니다.
- 생성되는 `quick` profile에 `gitleaks`, `headers`, `tls` 다음으로 native `openapi` scanner를 추가했습니다.
- OpenAPI version/server metadata 누락, plain HTTP server URL, effective security requirement가 없는 operation, 4xx/default client error response를 문서화하지 않은 operation finding을 추가했습니다.
- README, npm package README, CLI/config 문서, roadmap, changelog, risk 문서, release note를 0.2.1 scanner surface에 맞춰 갱신했습니다.

## 안전 메모

native OpenAPI scanner는 local JSON 또는 일반적인 YAML OpenAPI file을 읽습니다. remote spec을 다운로드하지 않고, API endpoint를 호출하지 않으며, credential 사용, crawling, fuzzing, attack template 실행을 하지 않습니다. URL 형태의 `--openapi` 입력은 이번 릴리스에서 거부합니다.

YAML reader는 새 dependency 없이 conservative하게 구현되어 있습니다. top-level `openapi`, `servers`, `security`, `paths`, operation `security`, response code가 있는 일반적인 OpenAPI YAML layout을 처리합니다. 복잡한 YAML 기능은 future parser upgrade가 명시적으로 검토되기 전까지 JSON으로 변환해서 사용하는 것이 좋습니다.

MCP 실행 범위는 이번 릴리스에서도 의도적으로 native headers scanner로 제한합니다.

## 호환성

기존 `scanrail doctor`, `scanrail init`, `scanrail setup`, `scanrail run --only headers`, `scanrail run --only gitleaks`, `scanrail run --only tls`, `scanrail run --profile quick`, `scanrail mcp serve` 흐름은 호환됩니다. 새로 생성되는 `quick` profile은 `openapi`를 포함하지만, OpenAPI spec이 없으면 profile 실행에서 skip reason을 리포트합니다. 기존 `scanrail.yaml`은 사용자가 수정하거나 재생성하기 전까지 기존 tool list를 유지합니다.

## 비목표

이번 릴리스는 OWASP ZAP, Nuclei, Schemathesis, Trivy, Semgrep, SBOM 생성, SARIF, testssl.sh, active DAST, remote OpenAPI fetching, API fuzzing, broader MCP scanner execution을 제공하지 않습니다. 상용 scanner parity도 주장하지 않습니다.
