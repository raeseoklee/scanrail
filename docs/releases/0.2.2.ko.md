# Scanrail 0.2.2 릴리스 노트

릴리스 일자: 2026-06-29

Scanrail 0.2.2는 v0.2 web/API 확장 트랙에서 문서화된 target safety 설정을 실제 실행 전에 강제하는 릴리스입니다. 더 무거운 active scanner를 붙이기 전에 공통 안전 경계를 먼저 고정합니다.

## 추가

- native interactive scanner용 shared web target guardrail validation을 추가했습니다.
- `targets.web.exclude_paths`, `safety.blocked_paths`, `safety.require_allowlist`, `safety.max_rps` runtime parsing을 추가했습니다.
- allowlist host/port matching, wildcard host matching, required allowlist, blocked path matching에 대한 safety test를 추가했습니다.

## 변경

- native `headers`, `tls` scan은 allowlist enforcement가 켜져 있으면 `targets.web.allowlist` 밖 target을 거부합니다.
- native `headers`, native `tls`, MCP-triggered headers scan은 target path가 `targets.web.exclude_paths` 또는 `safety.blocked_paths`와 일치하면 network contact 전에 거부합니다.
- interactive scanner capability requirement에 `blocked_paths`를 포함했고, native `headers`와 `tls`는 Scanrail preflight enforcement를 통해 해당 capability를 선언합니다.
- MCP config resource가 redacted guardrail field를 노출해 client가 활성 safety boundary를 확인할 수 있게 했습니다.

## 안전 경계

이번 릴리스는 ZAP, Nuclei, Schemathesis 같은 active scan engine을 추가하지 않습니다. 기존 native interactive scanner 실행 전에 target scope를 강제해 이후 adapter가 사용할 guardrail layer를 준비합니다.
