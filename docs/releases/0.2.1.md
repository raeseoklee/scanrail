# Scanrail 0.2.1 Release Notes

Release date: 2026-06-25

Scanrail 0.2.1 continues the v0.2 web/API expansion track with a conservative native OpenAPI baseline scanner. It reads local API contracts and reports contract-level security review signals without fetching remote specs or probing API endpoints.

## What Changed

- Added `scanrail run --only openapi` for local OpenAPI baseline checks.
- Added `--openapi <path>` to `scanrail init` and `scanrail run`.
- Added `targets.api.openapi` parsing to `scanrail.yaml`.
- Added the native `openapi` scanner to generated `quick` profiles after `gitleaks`, `headers`, and `tls`.
- Added OpenAPI findings for missing version/server metadata, plain HTTP server URLs, operations without effective security requirements, and operations that document responses without 4xx/default client error responses.
- Updated README, npm package README files, CLI/config docs, roadmap, changelog, risk docs, and release notes for the 0.2.1 scanner surface.

## Safety Notes

The native OpenAPI scanner reads a local JSON or common YAML OpenAPI file. It does not download remote specs, call API endpoints, use credentials, crawl, fuzz, or run attack templates. URL-valued `--openapi` inputs are rejected in this release.

The YAML reader is intentionally dependency-free and conservative. It handles common OpenAPI YAML layouts for top-level `openapi`, `servers`, `security`, `paths`, operation `security`, and response codes. Complex YAML features should be converted to JSON until a future parser upgrade is explicitly reviewed.

MCP execution remains intentionally limited to the native headers scanner in this release.

## Compatibility

Existing `scanrail doctor`, `scanrail init`, `scanrail setup`, `scanrail run --only headers`, `scanrail run --only gitleaks`, `scanrail run --only tls`, `scanrail run --profile quick`, and `scanrail mcp serve` workflows remain compatible. Newly generated `quick` profiles include `openapi`; if no OpenAPI spec is configured, profile runs skip it with evidence. Existing `scanrail.yaml` files keep their current tool list until users edit or regenerate them.

## Non-Goals

This release does not ship OWASP ZAP, Nuclei, Schemathesis, Trivy, Semgrep, SBOM generation, SARIF, testssl.sh, active DAST, remote OpenAPI fetching, API fuzzing, or broader MCP scanner execution. It also does not claim commercial scanner parity.
