# Scanrail 0.2.0 릴리스 노트

릴리스 일자: 2026-06-25

Scanrail 0.2.0은 v0.2 web/API 확장 트랙의 첫 조각으로 native TLS baseline scanner를 추가합니다. broader DAST와 API fuzzing은 후속 safety gate 뒤에 두고, Docker 없이 실행 가능한 HTTPS baseline 점검부터 제공합니다.

## 변경 사항

- HTTPS certificate/protocol baseline 점검용 `scanrail run --only tls`를 추가했습니다.
- 생성되는 `quick` profile에 `gitleaks`, `headers` 다음으로 native `tls` scanner를 추가했습니다.
- untrusted certificate chain, hostname mismatch, expired/soon-expiring certificate, TLS 1.2 미만 negotiated protocol finding을 추가했습니다.
- JSON/HTML report에서 high/critical severity가 명확히 표시되도록 스타일을 보강했습니다.
- README, npm package README, CLI/config/safety 문서, tool review, risk 문서, release note를 0.2.0 scanner surface에 맞춰 갱신했습니다.

## 안전 메모

native TLS scanner는 HTTPS target에 TLS connection 1개를 열고 HTTP request payload는 보내지 않습니다. 네트워크 target에 접속하므로 `interactive`로 분류하지만, crawling, fuzzing, redirect follow, attack template 실행은 하지 않습니다.

MCP 실행 범위는 이번 릴리스에서도 의도적으로 native headers scanner로 제한합니다. MCP scanner execution을 headers 밖으로 확장하려면 audit, target-boundary, host-compatibility 작업이 더 필요합니다.

## 호환성

기존 `scanrail doctor`, `scanrail init`, `scanrail setup`, `scanrail run --only headers`, `scanrail run --only gitleaks`, `scanrail run --profile quick`, `scanrail mcp serve` 흐름은 호환됩니다. 새로 생성되는 `quick` profile은 `tls`를 포함하지만, 기존 `scanrail.yaml`은 사용자가 수정하거나 재생성하기 전까지 기존 tool list를 유지합니다.

## 비목표

이번 릴리스는 OWASP ZAP, Nuclei, Schemathesis, Trivy, Semgrep, SBOM 생성, SARIF, testssl.sh, active DAST, broader MCP scanner execution을 제공하지 않습니다. 상용 scanner parity도 주장하지 않습니다.
